# Spam Email Detection using Naive Bayes

## Overview
This project is a Machine Learning-based Spam Email Detection system that classifies messages as Spam or Not Spam using the Naive Bayes algorithm. The application provides an interactive user interface for real-time message classification.

## Features
- Spam and Ham message classification
- Naive Bayes Machine Learning model
- Text vectorization using CountVectorizer
- Interactive user interface
- Real-time prediction
- Model persistence using Pickle

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Naive Bayes
- Streamlit/Flask
- Pickle

## Dataset
The project uses the SMSSpamCollection dataset containing labeled spam and ham messages.

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Text Vectorization
4. Model Training using Naive Bayes
5. Prediction and Classification
6. Result Display through UI

## Results
The system analyzes user-entered messages and predicts whether they are Spam or Not Spam.
